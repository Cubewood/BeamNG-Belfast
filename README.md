# BeamNG Belfast

A BeamNG.drive map of Belfast, built so a learner driver can practise for the Northern Ireland car test in VR. The roads need to be right; buildings only need to make it look like a city. The first area is around the Hydebank test centre (4 Hospital Road, BT8 8JL).

## Status

Early, milestone M0 (foundations). Nothing is built yet: there is no map, no level and no working pipeline. At this stage the repository holds the plan and the project conventions.

The approach is to use MapNG as the level generator and add Belfast data, UK road rules, road fixes and automated QA on top. See the plan for details.
