## Limits

- OSM crossing nodes (`highway=crossing` or any `crossing=*`) come from the side file `<area>.crossings.json` (I-002); MapNG's own filter never selected them, so the MapNG-facing cut `<area>.overpass.json` does not hold them. Signal nodes come from both files, once per node id. A mismatch is still a candidate for a person to check against a photo or the road, not a verdict: OSM can lag the street, and the DfI list can lag too.
- `highway=traffic_signals` nodes are junction signals as often as pedestrian crossings. A signal with no DfI point is not an error by itself.
- Ways (`highway=crossing` ways, footways with `footway=crossing`) are not used here.
- DfI covers signalised crossings and junctions with controlled facilities, and only some uncontrolled points; DfI does not separate pelican, puffin and toucan.
- Coordinates: DfI WGS84 from the portal; distances are great-circle.
